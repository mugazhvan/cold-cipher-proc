# KisanFlow: Full Technical Bibliography

This document serves as the complete repository of all sources referenced, used, or simulated within the KisanFlow project.

### 1. Government Policies & Domain Frameworks
*   **Ministry of Agriculture & Farmers Welfare, GoI**
    *   *Reference*: Minimum Support Prices (MSP) for Kharif/Rabi Crops.
    *   *Usage*: Simulated inside `mockData.ts` to calculate accurate DBT estimates based on exact crop types (e.g., Sharbati Wheat, Paddy Common).
*   **Haryana State Government**
    *   *Reference*: e-Kharid Portal Operations & Gate Pass Architecture.
    *   *Usage*: Studied the physical flow to design the 5-stage token tracking system.
*   **Punjab Mandi Board**
    *   *Reference*: Anaaj Kharid & e-Mandikaran Portal Workflows.
    *   *Usage*: Basis for standardizing the schema generated by `pdf_generator.py` for digital J-Forms.
*   **Directorate of Marketing & Inspection (DMI)**
    *   *Reference*: AGMARKNET Data Standards.
    *   *Usage*: Researched to ensure KisanFlow's API schemas remain interoperable with future e-NAM hooks.

### 2. Academic & Evaluation Reports
*   **CCS National Institute of Agricultural Marketing (NIAM)**
    *   *Reference*: Performance Evaluation of e-National Agriculture Market.
    *   *Usage*: Core foundational paper justifying the need for physical queue orchestration (KisanFlow) prior to digital trading (e-NAM).

### 3. Technology & Security Standards
*   **OWASP Foundation**
    *   *Reference*: JSON Web Token (JWT) Security Best Practices.
    *   *Usage*: Implemented in `security.py` using HMAC-SHA256 validation to prevent offline gate pass forgery.
*   **PostgreSQL Global Development Group**
    *   *Reference*: PostgreSQL 15 Documentation: Explicit Locking.
    *   *Usage*: Directly implemented in the slot booking API via `with_for_update()` to enforce ACID-compliant capacity limits and prevent overbooking.
*   **Mathematical Algorithms**
    *   *Reference*: Haversine Formula for Spherical Distance.
    *   *Usage*: Used in `geoUtils.ts` to compute localized radar distances without relying on paid Google Maps APIs.
*   **Cloud Infrastructure**
    *   *Reference*: Vercel & Render Pricing Pages (Sept 2026).
    *   *Usage*: Validated zero-cost prototype hosting feasibility.
